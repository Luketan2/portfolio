Images go here.

Folder layout:
  images/<project-id>/   one folder per project, named exactly after the
                         project's "id" in data/projects.js
  images/profile/        your profile / CV photos
  images/hero/           optional full-width home hero background images
  images/about/          optional extra photos shown on the About page

To use an image, drop the file into the right folder, then either:
  - reference it in data/projects.js as  images/<project-id>/yourfile.jpg
  - or open admin.html, click Refresh, and pick it visually.

The example-project/ folder contains a placeholder.svg you can delete once
you add your own images.
